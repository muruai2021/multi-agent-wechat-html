# 技能自我复盘模板

> 技能每次被调用后，根据输出结果决定是否触发自我复盘。
> 也可由用户手动触发：`/multi-agent-wechat-html self-review`

---

## 触发条件（满足任一自动触发）

1. 用户反馈"文章不对"、"排版乱了"、"还是AI味太重"
2. 文章渲染失败或脚本报错
3. 排版 verify.sh 验证项失败 ≥ 3 项
4. 手动触发：`/multi-agent-wechat-html self-review`

---

## 复盘流程

### 第一步：读取错误日志

读取 `references/failure_case_log.md`，确认：
- 是否有新的未修复错误案例
- 是否有同一触发词出错 ≥ 3 次（复发性问题）

### 第二步：根因分析

**问题类型分类：**
- 🐛 **Bug** — 写作流程错误、排版脚本失败
- 📖 **质量** — 去AI味不够、文章结构不完整
- 🎨 **排版** — HTML样式异常、渲染不正确
- 📦 **缺功能** — 缺少排版模式、缺少评审维度

**根因简述：**
[用一句话描述为什么会出错]

### 第三步：生成改进建议

| 优先级 | 改进措施 | 影响范围 |
|--------|----------|----------|
| P0 | [立即修复，不能再犯] | 所有文章场景 |
| P1 | [本迭代内修复] | 当前排版模式 |
| P2 | [下个版本规划] | 扩展排版能力 |

### 第四步：更新错误日志

将本次错误追加到 `references/failure_case_log.md`。

### 第五步：更新技能

根据改进建议，更新 SKILL.md 或相关脚本。

---

## 复盘后操作

| 结论 | 操作 |
|------|------|
| 排版脚本错误 | 修复 verify.sh 或排版脚本 |
| 文章质量不达标 | 调整去AI味prompt或写作Agent |
| 缺少评审维度 | 补充评审维度到 grading 流程 |
| 排版样式问题 | 修复 template.html 或 CSS |
